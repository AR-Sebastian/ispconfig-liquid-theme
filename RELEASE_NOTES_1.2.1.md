# LIQUID 1.2.1

## Deutsch

LIQUID 1.2.1 ist ein Wartungsrelease für die eigenständige Sprachdarstellung.
ISPConfig 3.3.1p1 liefert in der angemeldeten Oberfläche historisch ein festes
HTML-Sprachattribut. LIQUID erkennt die tatsächliche Oberflächensprache deshalb
jetzt über bereits übersetzte ISPConfig-Beschriftungen.

Damit erscheinen Dashboard-Zustände, Tabellenzähler, Filter, Seitennavigation,
Formularhinweise und barrierefreie Beschriftungen des Designschalters
einheitlich auf Deutsch oder Englisch. Das eigenständige dunkle
Liquid-Glass-Design sowie ISPConfig-Kern, API, Datenbank und Serveraktionen
bleiben unverändert.

Das Paket enthält 301 signierte Dateien und bestand Paket-, Neutralitäts-,
Offline-Installations-, Upgrade- und Rollback-Prüfungen. Version 1.2.0 bleibt
als unveränderliche Rückfallversion verfügbar.

## English

LIQUID 1.2.1 is a maintenance release for standalone locale consistency.
ISPConfig 3.3.1p1 historically emits a fixed HTML language attribute in the
authenticated interface, so LIQUID now resolves the actual interface language
from existing translated ISPConfig labels.

Dashboard states, table counts, filters, pagination, form feedback and
accessible theme-control labels now consistently follow German or English.
The independent dark-first liquid-glass presentation and ISPConfig core, API,
database and server-side actions remain unchanged.

The package contains 301 signed files and passed package, neutrality, offline
installation, upgrade and rollback validation. Version 1.2.0 remains available
as the immutable rollback release.

# ISPConfig LIQUID

LIQUID is the expressive premium theme for ISPConfig. It combines a dark-first
navy canvas, restrained violet and cyan light, translucent surfaces, clear
hierarchy and accessible contrast.

Version 1.1 closes the product composition across authentication, dashboard,
global search, dialogs, navigation, tables, forms, monitoring, the retained
Extension Installer and the optional Workbench Billing product. Light and dark
appearances now have separate contrast-safe navigation contracts.

The theme is a standalone sibling of NEXT. It shares the proven functional UI
engine but has its own templates, assets, preferences, dashboard layout and
release lifecycle. Installing or changing LIQUID never modifies NEXT.

## Design contract

- glass is used to establish depth, never to reduce readability;
- accent color identifies selection and primary actions, not system health;
- success, warning and danger retain their semantic colors;
- light and dark modes are first-class;
- reduced-motion and reduced-transparency preferences remain usable;
- mobile layouts reduce blur and decoration to protect performance.

## Installation

Copy the complete `liquid` directory to the ISPConfig theme directory and select
`liquid` in the user interface theme setting. Keep the stock `default` theme as
an operational fallback.

The package contains no ISPConfig core, database, API or service changes.
